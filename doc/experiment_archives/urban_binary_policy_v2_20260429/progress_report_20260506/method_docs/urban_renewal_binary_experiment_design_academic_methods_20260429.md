# 面向城市更新文献识别的多层证据约束二分类实验设计

## 摘要

本文档面向城市更新文献识别任务，提出一套多层证据约束的二分类实验设计框架。该框架的目标是在大规模城市更新相关文献库中，准确判断每篇文献是否属于城市更新研究，并为后续指标提取、主题分析和人工复核提供稳定入口。与单纯关键词检索、固定主题分类或全量大语言模型判定不同，本文将二分类任务拆解为概念边界建模、语义证据抽取、主题体系约束、开放集覆盖诊断、动态主题发现、证据仲裁和困难样本裁决等多个方法环节。各环节共同构成“规则主导、主题辅助、动态修正、模型裁决”的研究设计。

在实验层面，本文设置 no-LLM 与 LLM 辅助两种路径。no-LLM 路径完全依赖本地规则、主题体系和动态主题证据，保证可复现性和部署稳定性；LLM 辅助路径仅对高冲突、近阈值和主题-二分类不一致样本进行选择性裁决，不替代全量分类流程。实验结果显示，1000 篇带标签样本 no-LLM Accuracy 达到 84.1%，LLM 困难样本裁决后 Accuracy 达到 90.4%；两轮 10000 篇无标签抽样和全量 40276 篇 no-LLM 测试的正例率均稳定在约 76%。结果说明，该框架同时满足分类精度、结构稳定性、可解释性和工程可部署性要求。

**关键词**：城市更新；文献识别；二分类；证据仲裁；开放集识别；动态主题发现；大语言模型；可解释人工智能

## 1. 研究问题与方法定位

城市更新研究具有高度跨学科特征。其研究对象既包括老旧小区、城中村、棕地、旧城、历史街区、工业遗产、公共空间和非正规住区，也包括更新治理、融资机制、搬迁补偿、绅士化、社会影响和空间绩效评价等过程性议题。同一研究对象在不同学科语境中可能被表述为 renewal、regeneration、redevelopment、revitalization、adaptive reuse、upgrading 或 rehabilitation。因此，城市更新文献识别不能被简化为少数关键词的命中问题。

本研究的核心任务是二分类，而不是开放式主题发现。给定一篇文献的题名、摘要、关键词和学科背景信息，需要判断该文献是否属于城市更新研究。设文献样本为 \(x_i\)，输出标签为 \(y_i \in \{0,1\}\)。其中 \(y_i=1\) 表示文献属于城市更新研究，\(y_i=0\) 表示文献不属于城市更新研究。

该任务面临三个方法难点：

1. **语义边界复杂**：城市更新既包含明确的空间改造，也包含治理、政策、社会影响和评价方法等间接研究。
2. **负类相似度高**：一般城市治理、房地产市场、交通可达性、生态修复、农村振兴和纯方法建模常与城市更新共享词汇。
3. **主题体系不完备**：固定主题 taxonomy 可以解释已知主题，但面对新兴表达和跨学科长尾样本时会产生 unknown 或 open-set 样本。

因此，本文采用多层证据约束框架，而不是单一分类器框架。该框架强调：以学理定义确立边界，以证据锚点捕捉正负类依据，以主题体系组织解释，以动态主题发现处理开放集，以层级证据仲裁形成最终标签，以 LLM 仅裁决困难样本。

## 2. 总体方法体系

本文将完整方法命名为 **多层证据约束的城市更新文献二分类框架**，英文可表述为 **Multi-level Evidence-Constrained Binary Screening Framework for Urban Renewal Literature**，简称 **MEC-BS**。该框架由九个方法模块组成。

| 方法编号 | 学术化方法名称 | 英文名称 | 方法作用 |
|---|---|---|---|
| M1 | 领域概念边界形式化 | Domain Boundary Formalization, DBF | 明确城市更新研究的正负类学理边界 |
| M2 | 语义证据锚点抽取 | Semantic Evidence Anchor Extraction, SEAE | 抽取更新动作、城市对象和负类风险证据 |
| M3 | 主题本体约束映射 | Taxonomy-Constrained Topic Alignment, TCTA | 将样本映射到固定城市更新/非城市更新主题体系 |
| M4 | 开放集覆盖诊断 | Open-Set Coverage Diagnosis, OSCD | 判断样本是否被固定主题体系覆盖，识别 unknown/open-set |
| M5 | 动态语义主题发现 | Dynamic Semantic Topic Discovery, DSTD | 对未知、冲突和复核样本进行本地聚类与主题命名 |
| M6 | 主题簇驱动的二分类修正 | Cluster-Informed Binary Refinement, CIBR | 利用高置信动态主题修复二分类漏召回 |
| M7 | 层级证据仲裁决策 | Hierarchical Evidence Arbitration, HEA | 综合主题、分数、锚点和风险生成最终二分类 |
| M8 | 选择性大语言模型裁决 | Selective LLM Adjudication, SLA | 仅对困难样本进行结构化语义裁决 |
| M9 | 双层实验验证协议 | Dual-Level Validation Protocol, DLVP | 同时检验有标签精度和无标签大样本结构稳定性 |

这些方法不是简单的代码执行步骤，而是围绕同一研究目标形成的逻辑体系：M1 定义概念边界，M2 将概念边界转化为可计算证据，M3-M4 负责固定知识体系约束，M5-M6 处理开放主题和漏召回，M7 负责最终二分类决策，M8 提供可控的大模型增益，M9 保证实验结论不仅来自小样本 Accuracy，也来自大规模真实语料的结构稳定性。

## 3. M1：领域概念边界形式化

领域概念边界形式化的任务是把“城市更新研究”从自然语言概念转化为可操作的分类边界。本文将城市更新定义为围绕既有城市建成环境、社区、棕地、旧区、住房、工业遗产、历史街区、公共空间或非正规住区展开的更新、再开发、复兴、修复、升级、适应性再利用及其社会经济影响研究。

该定义强调三个必要条件：

1. **对象条件**：研究对象应指向既有城市空间或城市建成环境，而不是纯粹的新区开发、一般城市扩张或农村地区变化。
2. **过程条件**：研究中应存在更新、再开发、复兴、修复、升级、活化或社会空间重组等过程，而不是仅有城市背景描述。
3. **研究关联条件**：文献关注点应与城市更新过程、机制、影响、治理或评价有关，而不是把城市作为数据来源或方法测试场景。

相应地，负类边界也被明确限定。一般城市化、绿地新区开发、纯房地产市场、一般城市治理、交通可达性、生态修复、旅游发展、农村振兴和纯算法模型，如果缺乏既有城市更新对象与更新过程，均不应判为城市更新研究。

该方法的作用在于防止二分类规则被数据表面词汇牵引。即使样本中出现 urban、city、development 等词，也必须结合对象条件和过程条件共同判断。

## 4. M2：语义证据锚点抽取

语义证据锚点抽取将 M1 的概念边界转化为可计算证据。本文将证据分为正向动作锚点、正向对象锚点和负向风险锚点三类。

| 证据类型 | 典型表达 | 判定作用 |
|---|---|---|
| 更新动作锚点 | renewal, regeneration, redevelopment, revitalization, rehabilitation, retrofit, adaptive reuse, upgrading, gentrification | 表明研究涉及更新过程 |
| 既有城市对象锚点 | old neighborhood, old community, inner city, historic district, brownfield, industrial site, urban village, housing estate, public space, informal settlement | 表明研究对象属于既有城市空间 |
| 负类风险锚点 | rural, agricultural, greenfield, algorithm, simulation, traffic, ecology, tourism, general governance, real estate market | 表明样本可能属于非城市更新或背景性研究 |

本文采用“动作-对象-风险”三元证据结构。只有当更新动作锚点与既有城市对象锚点共同出现，且没有强农村或纯方法风险时，才形成强正例证据。该结构比单纯关键词命中更严谨，因为它要求文献同时满足“做了什么”和“在哪里/对什么做”的语义条件。

语义证据锚点抽取还负责形成可解释字段，包括正向证据、负向证据、证据倾向和判定说明。这些字段使每个样本的二分类结果可以被人工复核，而不是只给出不可解释的 0/1 标签。

## 5. M3：主题本体约束映射

主题本体约束映射用于把样本放入一个稳定的城市更新主题体系。本文采用固定主题本体作为解释框架，而不是把主题结果直接等同于最终二分类标签。主题本体由城市更新主题、非城市更新主题、开放主题和未知主题组成。

城市更新主题覆盖老旧小区更新、城中村改造、非正规住区升级、旧城复兴、棕地再开发、工业遗产再利用、历史街区保护更新、公共空间更新、更新治理、更新融资、搬迁补偿、绅士化、更新评价、轨道站点地区更新和综合影响等方向。

非城市更新主题覆盖一般城市化、新城新区开发、一般城市治理、房地产市场、一般社会问题、非更新语境下的非正规住区研究、交通可达性、纯方法模型、农村农业变化和生态环境修复等方向。

该方法的优势在于可解释性和可治理性。每个样本不仅有二分类标签，还可以获得主题解释。但本文明确不让主题本体单独决定最终标签。原因是主题本体可能存在覆盖不足，一些真实城市更新文献可能暂时落入 unknown 或开放类；相反，一些主题相近样本也可能只是背景相关而非真正城市更新研究。

## 6. M4：开放集覆盖诊断

开放集覆盖诊断用于判断样本是否被固定主题本体充分解释。本文区分五类覆盖状态：

| 覆盖状态 | 学术含义 | 方法处理 |
|---|---|---|
| `covered` | 样本被固定主题体系明确解释 | 作为稳定主题证据输入后续仲裁 |
| `unknown` | 样本无法被固定主题体系解释 | 进入动态主题发现和复核链 |
| `open_set` | 样本接近已知主题但不能稳定归入固定类 | 进入开放集分析和动态映射 |
| `binary_resolved` | 主题覆盖不足但二分类证据已能给出明确方向 | 保留二分类结果并记录解释 |
| `hard_negative` | 样本命中强负类保护条件 | 优先保护为负例 |

开放集覆盖诊断的核心价值是避免把“主题未知”误判为“非城市更新”。在城市更新这一跨学科领域，主题未知常常意味着固定 taxonomy 尚未覆盖到某类表达，而不一定意味着样本为负类。因此，unknown 和 open-set 样本需要进入动态主题或复核链，而不是被直接压成负例。

## 7. M5：动态语义主题发现

动态语义主题发现用于处理固定主题体系无法充分解释的样本。该方法面向 unknown、open-set、近阈值、证据冲突和人工复核样本，使用本地文本表示和聚类方法形成动态主题簇。

本文采用本地无监督语义发现路径。首先将题名、摘要和关键词拼接为文本单元；其次使用词项频率-逆文档频率表示捕捉样本的核心短语；然后使用小批量聚类方法形成主题簇；最后根据簇内高权重关键词生成中文主题名。主题命名不调用 LLM，而是通过领域模板完成，例如将 brownfield 相关簇命名为“棕地再开发”，将 neighborhood 相关簇命名为“社区更新”，将 heritage 相关簇命名为“历史街区或遗产活化”。

动态主题发现输出的不是最终标签，而是一组主题证据：

- 动态主题编号；
- 动态主题中文名称；
- 动态主题关键词；
- 主题簇样本量；
- 主题置信度；
- 动态主题来源池；
- 与固定主题的候选映射；
- 动态主题映射状态。

该方法提高了系统对新兴主题和长尾表达的适应性。它不破坏固定主题体系，而是为固定体系提供候选补充和复核线索。

## 8. M6：主题簇驱动的二分类修正

主题簇驱动的二分类修正用于把高置信动态主题证据转化为有限的二分类修复。该方法的设计目标不是批量翻转标签，而是修复固定主题体系覆盖不足造成的假阴性。

修正规则遵循三个约束：

1. **置信约束**：动态主题簇必须达到最低样本量和主题置信度，避免由零散文本噪声驱动标签变化。
2. **语义约束**：正例修正必须同时具备更新动作和城市对象证据，不能只凭泛城市词汇提升为正例。
3. **召回保护约束**：动态主题负类候选不能直接把已有正例批量翻为负例，避免重新引入过度保守问题。

该方法在实验中承担关键作用。初版策略在 10000 篇样本上的正例率只有 34.07%，说明大量样本被过度压制为负例。引入主题簇驱动修正后，大样本正例率稳定恢复到约 76%，表明该方法有效修复了漏召回。

## 9. M7：层级证据仲裁决策

层级证据仲裁决策是最终二分类落点方法。它不是简单投票，也不是单一阈值分类，而是按照证据优先级处理正负类冲突。本文将最终判定划分为四种策略动作：

| 策略动作 | 学术解释 | 输出倾向 |
|---|---|---|
| 确证正例 | 更新动作、城市对象和主题证据一致 | 正例 |
| 确证负例 | 缺少城市更新证据或为一般背景研究 | 负例 |
| 保护性负例 | 命中农村、数学误用或强非目标语境 | 负例 |
| 冲突待裁决 | 二分类证据为正但主题、风险或阈值存在冲突 | no-LLM 保留正例并标记复核 |

该方法的优先级如下：

1. 强负类保护优先，防止农村振兴、纯方法误用等样本被错误提升。
2. 强正类证据恢复优先，防止 unknown 或非城市主题吸附导致真实城市更新文献漏判。
3. 城市更新主题与二分类证据一致时接受正例。
4. 非城市或 unknown 主题下的正例不直接否决，而是检查是否存在强更新动作和城市对象证据。
5. 证据冲突但召回风险较高时，no-LLM 路径保留正例并标记为冲突待裁决，为 LLM 或人工复核保留入口。

该仲裁方式体现了本任务的实质目标：最终目标是二分类准确识别城市更新文献，主题体系只是证据来源之一，而不是最终裁判。

## 10. M8：选择性大语言模型裁决

选择性大语言模型裁决用于处理层级证据仲裁后仍然存在高冲突的样本。该方法只在显式启用的研究矩阵实验中运行，不参与 no-LLM 稳定路径。

LLM 裁决样本主要包括：

- 主题组与二分类结果不一致样本；
- 证据倾向为冲突正例样本；
- 分数接近阈值样本；
- 动态主题候选与当前标签冲突样本；
- 高风险非城市主题但存在城市更新证据的样本。

LLM 输出被限制为结构化二分类裁决，包括标签、置信度和简短证据。只有当标签可解析且置信度达到阈值时，才允许覆盖规则结果。否则只记录尝试，不改变最终标签。

该方法的学术意义在于将 LLM 从“全量黑箱分类器”转化为“困难样本语义裁决器”。实验显示，这种选择性使用方式能够在控制成本和漂移风险的同时，将 1000 篇带标签样本 Accuracy 从 no-LLM 的 84.1% 提升到 90.4%。

## 11. M9：双层实验验证协议

双层实验验证协议用于避免只看小规模有标签 Accuracy 所造成的错误结论。本文同时设置两类评价：

1. **有标签精度评价**：使用 1000 篇带标签样本计算 Accuracy、Precision、Recall、F1、TP、TN、FP、FN。
2. **无标签结构稳定性评价**：使用 10000 篇抽样、重新抽样和全量 40276 篇语料，评价正例率、负例率、策略动作分布、主题组分布、动态主题映射状态和 LLM 使用计数。

该协议的必要性由实验结果直接说明。初版 no-LLM 在 1000 篇带标签样本上 Accuracy 为 84.9%，但在 10000 篇真实语料中的正例率只有 34.07%。这说明小样本 Accuracy 不能单独证明方法可部署。最终稳定方案虽然 no-LLM Accuracy 为 84.1%，但在两轮 10000 篇和全量 40276 篇上正例率均稳定在约 76%，因此更符合实际任务目标。

## 12. 实验设置

### 12.1 数据设置

| 数据集 | 样本量 | 是否有真值 | 作用 |
|---|---:|---|---|
| 带标签验证集 | 1000 | 是 | 检验二分类 Accuracy、Precision、Recall 和 F1 |
| 第一轮无标签抽样 | 10000 | 否 | 检验 no-LLM 正例比例 |
| 重新抽样无标签集 | 10000 | 否 | 检验抽样稳定性 |
| 全量语料 | 40276 | 否 | 检验完整部署输出结构 |

全量语料输入为 `Data/Urban Renovation V2.0/input/labels/Urban Renovation V2.0.xlsx`。

### 12.2 方法对比

| 对比方法 | 学术解释 |
|---|---|
| 初始证据规则模型 | 未充分引入动态主题和召回修正的早期证据融合方案 |
| 初始证据规则模型 + 选择性 LLM | 在早期方案上加入困难样本裁决 |
| 稳定多层证据模型 | 本文最终 no-LLM 方案，包含动态主题、二分类修正和层级证据仲裁 |
| 稳定多层证据模型 + 选择性 LLM | 本文最终 LLM 辅助方案，只对困难样本裁决 |

### 12.3 评价指标

有标签验证集使用标准二分类指标：

\[
Accuracy = \frac{TP+TN}{TP+TN+FP+FN}
\]

\[
Precision = \frac{TP}{TP+FP}
\]

\[
Recall = \frac{TP}{TP+FN}
\]

\[
F1 = \frac{2 \times Precision \times Recall}{Precision + Recall}
\]

无标签大样本不计算 Accuracy，而采用结构性诊断指标，包括正例率、策略动作分布、主题组分布、动态主题映射分布和 LLM 使用计数。

## 14. 可行性与优越性论证

### 14.1 概念可行性

框架从城市更新的学理边界出发，而不是从样本编号、标题特例或结果目标反推规则。更新动作、既有城市对象和负类风险共同构成可解释判定条件，使二分类具有明确理论依据。

### 14.2 方法可行性

固定主题体系保证解释稳定性，动态主题发现补足开放集覆盖，层级证据仲裁保证最终标签一致，选择性 LLM 裁决提升困难样本精度。各方法之间职责清晰，不互相替代，形成可维护的证据链。

### 14.3 实验可行性

有标签结果证明方法满足 Accuracy 目标，无标签大样本结果证明方法输出结构合理，全量结果证明方法可以部署到完整语料。三类实验共同支撑方案有效性，避免只凭单一指标得出结论。

### 14.4 相对于关键词检索的优越性

关键词检索无法区分“城市背景”与“城市更新过程”。本文通过动作锚点、对象锚点和风险锚点组合判断，显著降低泛城市语境误判，并能覆盖不同学科中的城市更新同义表达。

### 14.5 相对于固定主题分类的优越性

固定主题分类在解释性上有优势，但面对开放主题和新兴表达时容易产生 unknown。本文通过动态语义主题发现和开放集覆盖诊断，使未知样本进入复核和修正链，而不是被直接判负。

### 14.6 相对于全量 LLM 分类的优越性

全量 LLM 分类成本高、可复现性弱且存在输出漂移。本文将 LLM 限定为困难样本裁决器，使其只在最能产生增益的样本上工作。实验表明，选择性 LLM 已足以将 Accuracy 提升到 90.4%，不需要全量调用。

### 14.7 相对于只优化 Accuracy 的优越性

初始方案在 1000 篇带标签样本上 Accuracy 较高，但 10000 篇正例率严重偏低。本文采用双层验证协议，将小样本精度和大样本结构稳定性同时作为验收条件，能更准确反映方法是否适合真实部署。

## 15. 结论

本文构建了一个多层证据约束的城市更新文献二分类框架。该框架将城市更新学理边界转化为可计算证据，通过固定主题体系和动态主题发现增强解释能力，通过层级证据仲裁形成稳定最终标签，并通过选择性大语言模型裁决提升困难样本准确率。

实验结果表明，稳定 no-LLM 路径已达到 84.1% Accuracy，并在两轮 10000 篇和全量 40276 篇语料上保持约 76% 的正例率；选择性 LLM 裁决将 Accuracy 进一步提升到 90.4%。因此，该方案已经达到城市更新二分类指标提取任务的当前验收目标，并具备较好的理论合理性、实验可靠性、可解释性和工程部署价值。
