# 城市更新二分类任务进度汇报提纲

## 1. 任务目标

- 最终目标是准确完成城市更新研究文献二分类。
- 输出字段为 `final_label`、`urban_flag`、`是否属于城市更新研究`，三列保持一致。
- 主题发现、taxonomy 和动态主题均服务于最终二分类和可解释性。

## 2. 方法体系

- 总体框架：多层证据约束的城市更新文献二分类框架（MEC-BS）。
- M1 领域概念边界形式化：定义城市更新正负类边界。
- M2 语义证据锚点抽取：抽取更新动作、城市对象和负类风险。
- M3 主题本体约束映射：用固定 taxonomy 提供主题解释。
- M4 开放集覆盖诊断：识别 unknown、open_set、binary_resolved 等状态。
- M5 动态语义主题发现：本地聚类识别固定 taxonomy 未覆盖主题。
- M6 主题簇驱动的二分类修正：修复漏召回。
- M7 层级证据仲裁决策：统一落定最终二分类。
- M8 选择性 LLM 裁决：只处理困难样本。
- M9 双层实验验证协议：同时看 1000 有标签指标和大样本结构稳定性。

## 3. 实验结果

- no-LLM 有标签 Accuracy：84.1%。
- LLM 困难样本裁决 Accuracy：90.4%。
- 10000 第一轮 no-LLM 正例率：76.65%。
- 10000 重新抽样 no-LLM 正例率：75.86%。
- 全量 40276 no-LLM 正例率：76.40%。
- 全量 no-LLM：llm_used_sum=0，llm_attempted_sum=0。

## 4. 进展判断

- 当前二分类任务已达到预设验收目标。
- no-LLM 路径具备可复现性和稳定部署能力。
- LLM 路径证明困难样本裁决能进一步提升精度。
- 大样本与全量结果证明方法不是对 1000 样本过拟合。
