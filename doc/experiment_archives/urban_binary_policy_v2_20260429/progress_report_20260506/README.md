## 包内文件

- `城市更新二分类实验数据汇总_20260506.xlsx`：进度汇报用核心数据表，包含指标、分布、方法体系和原始工件索引。
- `城市更新二分类任务进度汇报_20260506.docx`：可直接汇报的 Word 说明稿。
- `城市更新二分类汇报提纲_20260506.md`：口头汇报或制作 PPT 的提纲。
- `data_tables/`：实验 CSV 摘要和分布统计副本。
- `method_docs/`：实验设计、流程说明、复现命令和论文实验段落文档副本。

## 使用建议

汇报时建议先打开 Word 文档说明研究目标、方法体系和达标结果，再用 Excel 的 `汇报摘要`、`有标签评估` 和 `无标签结构诊断` sheet 展示关键数据。大型预测工作簿保留在 `Data/.../runs/...`，不复制进本汇报包；其路径见 Excel 的 `原始工件索引` sheet。
